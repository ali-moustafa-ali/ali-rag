# Dashboard Directory

This directory contains the dashboard control system for the Ali RAG application.

## Structure

- `api/` - API endpoints
- `controllers/` - Business logic controllers  
- `models/` - Data models
- `config/` - Configuration files
- `middleware/` - Express middleware

## Getting Started

```bash
cd dashboard
npm install
npm run dev
```

## Features

- [ ] Document management
- [ ] RAG model configuration
- [ ] Analytics and monitoring
- [ ] User management
- [ ] System settings
- [ ] API endpoints

## API Endpoints

- `POST /api/documents` - Upload documents
- `GET /api/documents` - List documents
- `POST /api/query` - Process RAG queries
- `GET /api/analytics` - System analytics
