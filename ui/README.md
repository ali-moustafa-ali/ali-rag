# UI Directory

This directory contains the user interface components for the Ali RAG application.

## Structure

- `components/` - React components
- `pages/` - Page components
- `styles/` - CSS/styling files
- `hooks/` - Custom React hooks
- `types/` - TypeScript type definitions

## Getting Started

```bash
cd ui
npm install
npm run dev
```
